# FootballManager

   This is a fantasy-league like project where you can create your own team and participate in leagues and tournaments with other people. It's luck-based, meaning that teams or players don't have statistics. Additionally, there is an automated league and tournament every week. Although you can't join them, you can participate by betting on the winning team of a match, the league or the tournament.


## Historical source (July 2024)

This is the original office-and-friends football league project, first committed on
16 July 2024. The historical snapshots were sanitized on 27 September 2026: match
simulation, fixture/tournament generation, background orchestration and probability
weights have been replaced with explicit implementation stubs; local configuration
values have also been removed. Original author and committer timestamps and unrelated
source content were retained. Affected commit identifiers necessarily changed.

This public archive is intentionally not a runnable game: supply your own service
implementations and configuration. New development continues separately as EinManager.
